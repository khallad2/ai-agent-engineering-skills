# High-Retention Tech Script Writer Skill

When given a technical topic or project build, write the script using this exact retention formula:

1. **0:00–0:05 (The Visual Proof Hook):**
   - Start immediately with the working app/result on screen. Zero greeting ("السلام عليكم" comes later or not at all).
   - State the outcome + time/cost saved in one punchy Arabic sentence.
2. **0:05–0:30 (The Architecture Gap & Open Loop):**
   - Show why 90% of people fail when doing this the naive way ("غلطة الـ Vibe Coders").
   - Tease the critical fix that happens in the middle of the video (keeps viewers past the 1:30 and 4:00 mid-rolls).
3. **Body Structure (Every 3 minutes):**
   - Alternate between **Concept Diagram (30s)** → **Live Build/Code (2m)** → **Mini-Payoff + Re-hook (30s)**.
   - Place explicit chapter transitions at **01:30**, **04:00**, **08:00**, and **12:00** for clean manual mid-roll ad breaks.
4. **Embedded Funnel CTA (Minute 4:30 & Outro):**
   - Tie the free **Skills Pack** or **Course Waitlist** directly to the code shown on screen ("بدل ما تكتب القواعد دي من الصفر، سيبتلك الـ Skills Pack كامل في أول رابط في الوصف").
